# Vefsíðugerð á GitHub

## Nauðsynleg forrit sótt

!!! Info "Að sækja nauðsynleg forrit"

    Sæktu eftirfarandi forrit og settu þau upp í tölvunni þinni: 
    
    Smelltu á hlekkinn [hér](https://code.visualstudio.com/) til að sækja Visual Studio Code.

    Smelltu á hlekkinn [hér](https://www.python.org/downloads/) til að sækja Python.

## Að búa til Repository á GitHub

!!! Info "Að stofna aðgang á GitHub"

    Byrjaðu á að búa til notendaaðgang fyrir þig á GitHub. Smelltu á hlekkinn [hér](https://github.com/).
